## 실행

이 과제 폴더에서 Python 3으로 실행합니다:

```sh
python3 -c "from ex0.ft_hello_garden import ft_hello_garden; ft_hello_garden()"
```

각 과제는 함수를 정의합니다. 실행하려면 함수를 가져와 호출해야 하며, 파일만 실행하면 함수가 호출되지 않습니다.
