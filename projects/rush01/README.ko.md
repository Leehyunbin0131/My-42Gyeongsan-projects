# C Piscine Rush 01

각 행과 열에서 값이 중복되지 않고, 가장자리 단서가 지정하는 수만큼 건물이 보이도록
격자 퍼즐을 푸는 C 프로그램입니다. 후보 높이를 재귀적으로 탐색하며 가시성 조건을 검사합니다.

## 빌드 및 실행

이 과제 폴더에서 실행합니다:

```sh
cc -Wall -Wextra -Werror ex00/*.c -o rush-01
./rush-01 "4 3 2 1 1 2 2 2 4 3 2 1 1 2 2 2"
```

공백으로 구분한 단서들을 따옴표로 묶어 하나의 인자로 전달합니다.
단서는 위쪽, 아래쪽, 왼쪽, 오른쪽 순서입니다. 위 예시는 4×4 퍼즐입니다.

## 구성

- `ex00/`: 제출한 프로그램과 풀이 코드.
- `solution_mk2.c`, `solution_mk3.c`: 원본 저장소에서 보관한 다른 풀이 버전입니다.
  위 빌드 명령에는 포함되지 않습니다.

원본 소스와 기여자 정보가 담긴 헤더를 유지했습니다. 원본 저장소와 커밋은
[sources.json](../../sources.json)에 기록되어 있습니다.
