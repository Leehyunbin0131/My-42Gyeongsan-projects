# mazegen

표준 라이브러리만 사용하는 Python 3.10 이상용 미로 생성기입니다.
설정 파일을 읽거나 파일을 쓰지 않으며, MLX에 의존하지 않습니다.
`MazeGenerator(...)`를 호출하면 미로를 생성하고 최단 경로를 찾습니다.

[Blue Oak Model License 1.0.0](https://blueoakcouncil.org/license/1.0.0)은 재사용, 수정, 재배포를 허용합니다.
재배포 시 라이선스 전문이나 공식 링크를 제공해야 합니다.
소스 코드 공개나 변경 사항 표시는 요구하지 않습니다.
기여자가 허가할 수 있는 범위의 특허 사용권을 포함하지만, 제삼자의 특허 청구에 대한 보장은 아닙니다.
라이선스 전문은 wheel에 포함되어 있습니다.

## 설치 및 사용

Python 가상 환경에서 wheel이 있는 폴더로 이동한 뒤 실행합니다:

~~~sh
python3 -m pip install ./mazegen-1.0.0-py3-none-any.whl
~~~

~~~python
from random import Random

from mazegen import EAST_BIT, MazeGenerator

rng = Random(42)
maze = MazeGenerator(25, 17, (0, 0), (24, 16), rng=rng, perfect=False)

print(maze.walls[0][0])
print(maze.entry, maze.exit)
print(maze.path)
print(bool(maze.walls[0][0] & EAST_BIT))
~~~

## 매개변수

| 이름 | 의미 |
| --- | --- |
| `width`, `height` | 양의 정수: 열 개수와 행 개수 |
| `entry_cell`, `exit_cell` | 서로 다른 입구·출구 좌표, `(x, y)` |
| `rng` | 필수 키워드 인자: 호출자가 관리하는 `random.Random` 인스턴스 |
| `perfect` | 키워드 인자, 기본값 `False`; `True`이면 순환 경로가 없는 미로 생성 |

새 `Random(42)` 인스턴스를 사용하면 같은 크기·양 끝점·모드·코드·Python 환경에서 같은 미로를 재현합니다.
`rng` 객체를 재사용하면 난수열을 이어서 사용합니다.
고정 시드 없이 시작하려면 `Random()`을 사용합니다. 각각의 생성 결과가 반드시 서로 다른 미로인 것은 아닙니다.

양 끝점은 범위 안에 있어야 하며, 막힌 `42` 칸과 겹치면 안 됩니다.
기본 모드는 독립적인 순환 경로가 최소 두 개 필요하므로 `(width - 1) * (height - 1) < 2`인 크기를 거부합니다.
크기나 좌표가 유효하지 않으면 `ValueError`가 발생합니다.

## 결과 읽기

- `walls: tuple[bytes, ...]`: 벽 코드이며, `walls[y][x]`로 접근합니다.
- `entry`, `exit`: 양 끝점의 `(x, y)` 좌표입니다.
- `path: tuple[tuple[int, int], ...]`: 양 끝점을 포함한 최단 경로입니다.

벽 비트는 `NORTH_BIT=1`, `EAST_BIT=2`, `SOUTH_BIT=4`, `WEST_BIT=8`입니다.
**비트가 설정되어 있으면 벽, 해제되어 있으면 통로입니다.**
생성 결과에서 `ALL_WALLS=15`는 완전히 막힌 `42` 칸을 나타냅니다.
이 상수들과 `Coord` 타입 별칭도 `mazegen`에서 가져올 수 있습니다.
`Coord`는 `tuple[int, int]`, 즉 `(x, y)` 좌표이며, 생성 과정에서 사용하는 일차원 정수 칸 인덱스가 아닙니다.

벽의 각 행과 경로는 불변 값이지만, 객체 속성에 새 값을 대입하는 것까지 막지는 않습니다.
결과는 읽기 전용으로 취급하고, 새 미로가 필요하면 새 인스턴스를 만드세요.

## 알고리즘 및 제약

반복 방식의 무작위 DFS로 이동 가능한 모든 칸을 연결합니다.
`perfect=True`이면 임의의 두 이동 가능한 칸 사이에 정확히 하나의 경로가 있는 트리를 유지합니다.
기본 모드는 막다른 길의 벽을 열고, 필요한 경우 통로를 더 추가해 독립적인 순환 경로 두 개를 확보합니다.
BFS로 결과 미로의 최단 경로를 찾습니다.

완전히 열린 `3x3` 영역을 방지하는 성질은 DFS와 현재의 행 우선 브레이딩 처리, 북·동·남·서 선택 순서에 의존합니다.
알고리즘이나 순서를 바꾸기 전에 이 성질을 다시 확인해야 합니다.
`42` 패턴 때문에 생기는 작은 막힌 구역은 남습니다. 제공된 분석기에서 `real dead-ends`가 0이라고 해서
모든 칸에 통로가 두 개 이상 있다는 뜻은 아닙니다.
또한 독립적인 순환 경로 두 개가 있다고 해서 모든 두 칸 사이에 독립적인 경로 두 개가 보장되는 것은 아닙니다.

고정된 `7x5` 패턴은 `((width - 7) // 2, (height - 5) // 2)`에서 시작합니다.
연결성을 유지하려면 최소 `8x6`이 필요합니다.
정확히 `8x6`일 때 패턴은 모서리를 차지하며, 완전 미로 모드에서만 배치됩니다.
기본 모드는 최소 `8x7` 또는 `9x6`이 필요합니다.
패턴이 들어가지 않으면 패턴 없이 생성을 진행합니다.
라이브러리는 경고를 출력하지 않으며, 사용자에게 보여줄 메시지는 호출자가 처리합니다.
