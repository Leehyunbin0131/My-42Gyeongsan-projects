# 42 경산 C Piscine

42 경산에서 작성한 C Piscine 연습 과제를 담고 있습니다.

Piscine은 작은 연습 과제를 통해 C 프로그래밍, Unix 기초, 문제 해결을 집중적으로 다루는 과정입니다.
각 폴더는 원래 42 Piscine 과제의 구조를 따릅니다.

## 구성

| 모듈 | 내용 |
| --- | --- |
| `C_Piscine_C_00` | 기본 출력, 반복문, 숫자 출력 |
| `C_Piscine_C_01` | 포인터, 배열, 문자열 출력, 정수 배열 |
| `C_Piscine_C_02` | 문자열 복사·검사·변환 함수 |
| `C_Piscine_C_03` | 문자열 비교, 연결, 검색 |
| `C_Piscine_C_04` | 문자열 길이, 숫자 출력, `atoi`, 진법 변환 |
| `C_Piscine_C_05` | 재귀, 거듭제곱, 피보나치 수열, 제곱근, 소수 |
| `C_Piscine_C_06` | 명령줄 인자 |
| `C_Piscine_C_07` | 동적 할당과 문자열 연결 |
| `C_Piscine_C_08` | 헤더 파일과 매크로 |

## 참고 사항

이 연습 과제들은 학습 기록으로 보관하고 있습니다. 코드는 원래 42 Piscine 과제의 제약 조건을 따르므로,
일반적인 C 프로젝트에서 사용할 수 있는 표준 라이브러리 함수도 일부 사용하지 않습니다.
