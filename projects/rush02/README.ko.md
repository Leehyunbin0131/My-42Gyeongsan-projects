# C Piscine Rush 02

숫자 사전을 사용해 0 이상의 정수를 단어로 변환하는 C 프로그램입니다.
사전 파싱, 유효성 검사, 숫자 자릿수 묶음 처리를 포함합니다.

## 빌드 및 실행

이 과제 폴더에서 실행합니다:

```sh
cd ex00
make
./rush-02 42
./rush-02 numbers.dict 123
```

첫 번째 실행 방식은 현재 작업 폴더의 `numbers.dict`를 사용합니다.
두 번째 방식은 사전 경로를 직접 지정합니다. 제공된 사전에는 영어 숫자 이름이 들어 있으며,
`42`를 입력하면 `forty two`를 출력합니다.

`make clean`은 오브젝트 파일을, `make fclean`은 오브젝트 파일과 실행 파일을 삭제합니다.

원본 소스와 기여자 정보가 담긴 헤더를 유지했습니다. 원본 저장소와 커밋은
[sources.json](../../sources.json)에 기록되어 있습니다.
