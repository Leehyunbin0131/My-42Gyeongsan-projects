# BSQ

동적 계획법을 사용해 지도에서 장애물이 없는 가장 큰 정사각형을 찾고 채우는
C Piscine 과제입니다. 지도 파일과 표준 입력을 지원합니다.

## 빌드 및 실행

이 과제 폴더에서 실행합니다:

```sh
make
./bsq map.txt
./bsq first-map.txt second-map.txt
./bsq < map.txt
```

지도 헤더는 행 개수와 서로 다른 세 문자로 구성됩니다.
세 문자는 차례로 빈 공간, 장애물, 채울 영역을 나타냅니다. 예시는 다음과 같습니다:

```text
4.ox
....
....
....
....
```

이 예시는 `xxxx`를 네 줄 출력합니다. `make clean`은 오브젝트 파일을,
`make fclean`은 오브젝트 파일과 실행 파일을 삭제합니다.

## 소스 구성

- `src/`: 입력 파싱, 지도 처리, 동적 계획법, 출력.
- `include/`: 프로젝트 헤더.

원본 소스와 기여자 정보가 담긴 헤더를 유지했습니다. 원본 저장소와 커밋은
[sources.json](../../sources.json)에 기록되어 있습니다.
